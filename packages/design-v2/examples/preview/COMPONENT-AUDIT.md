## 当前批量实现说明

- `componentRegistry.ts` 已预填 68 个组件的候选状态、尺寸和变量绑定，供后续核验使用；这些候选资料不等于已核验设计证据。
- `ComponentDemo.tsx` 已拆分为注册表驱动的 demo 与通用 Fidelity Surface；通用外壳只证明路由和主题消费，不证明视觉等价。
- 已严格完成的 aligned 组件目前为 Accordion、Alert、Alert Dialog、Aspect Ratio、Avatar、Badge、Breadcrumb、Button Group、Calendar、Card、Carousel、Chart、Checkbox、Collapsible、Combobox、Command、Context Menu、Data Table、Date Picker、Dialog、Drawer、Dropdown Menu、Empty、Field、Hover Card、Input OTP、Input Group、Item、Kbd、Input、Menubar、Navigation Menu、Pagination、Popover、Progress、Radio Group、Resizable、Scroll Area、Select Menu、Separator、Sheet、Sidebar、Skeleton、Slider、Spinner、Sonner、Switch、Table、Tabs、Textarea、Toggle、Toggle Group、Tooltip。
- 已完成 Figma 右栏读取并完成 localhost 并排视觉核验的组件共 66 个；仅 Direction、Label 因 Figma 当前页面缺少可选 Components 节点而保留为“设计节点缺失”，不伪造对齐结论。
- Direction、Label 的 Figma 页当前只有页面级 Auto layout，未暴露可选 Components 节点，因此单独标记为“设计节点缺失”，不伪造右栏证据。
- Light/Dark 已改为站点主题切换的单组渲染；Figma 文件始终只读，未执行提交。
